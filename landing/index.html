[01] Features

필요한 것만 남기고,
나머지는 엔진에 맡기세요.

화려한 설정 화면 대신 정밀한 규칙 하나에 집중합니다. 정의는 한 번, 실행은 어떤 OS에서든 동일하게.

Single Source, Dual OS

하나의 정의 파일에서 Windows용 AutoHotkey 스크립트와 macOS용 Karabiner 설정을 동시에 빌드합니다. 수정은 한 곳에서만.

        [03] Use Cases
        
매일 반복되는 손동작을 지웁니다.

      

      

        

          
01

          
반복 행정·문서 업무

          
결재 상신 문구, 회신 메일 서두, 오늘 날짜와 문서 번호처럼 매일 같은 내용을 치는 시간을 트리거 몇 글자로 줄입니다. 한글 입력 상태에서도 그대로 동작합니다.

          

            
;ok검토 완료 회신 문구

            
;today2026-11-23

        [04] FAQ
        
도입 전에
자주 묻는 질문.

        
찾는 답이 없다면 GitHub 이슈로 남겨 주세요. 메인테이너가 직접 답변합니다.

        이슈 남기기
      

      

        

          
          
규칙은 플랫폼 중립적인 정의 파일 하나로 관리합니다. 빌드할 때 Windows용 AutoHotkey v2 스크립트와 macOS용 Karabiner-Elements 설정으로 각각 변환되며, Ctrl과 ⌘처럼 OS마다 다른 수정 키는 매핑 테이블에 따라 자동으로 보정됩니다.

        

        

          
          
트리거를 글자가 아닌 물리 키 시퀀스로 감지합니다. 한글 상태에서 ;mail을 쳐서 화면에 ;ㅡ먀ㅣ가 찍히더라도 같은 규칙으로 인식하고, 확장 결과는 IME 조합과 충돌하지 않도록 유니코드로 직접 입력됩니다.

        

        

          
          
네. 계정 가입, 클라우드 동기화, 사용 통계 수집이 전혀 없고, 설치 후에는 네트워크 연결 없이 100% 로컬에서 동작합니다. 규칙 파일은 사람이 읽을 수 있는 텍스트라 보안 검토도 간단합니다.

        

        

          
          
AutoHotkey 스크립트의 핫스트링·리매핑 구문과 Excel(.xlsx) 규칙 시트를 그대로 가져올 수 있습니다. 변환할 수 없는 구문은 건너뛴 뒤 목록으로 알려 드리므로 하나씩 확인하며 옮기면 됩니다.

        

        

          
          
개인 용도와 업무 용도 모두 무료입니다. 소스 코드는 GitHub에 공개되어 있으며, 팀 단위로 배포할 때도 별도 비용이 들지 않습니다.
